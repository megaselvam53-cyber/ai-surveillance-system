🚨 AI Surveillance System  

---

📌 Project Overview  

AI Surveillance System is a smart and user-friendly web application built using computer vision and deep learning.  

It helps security personnel monitor and detect human presence in images, videos, and live camera feeds in real-time.  

The system also generates automated reports and displays the latest detection results on a dashboard.  

---

💻 Technologies Used  

• Python  
• Flask  
• OpenCV  
• YOLOv8 (Ultralytics)  
• HTML  
• CSS  
• ReportLab  

---

⚙️ Features  

👮 Security Module  

• Role-based login system  
• Upload image/video for detection  
• Real-time live camera monitoring 🎥  
• Detect persons using AI model  
• Dashboard showing latest detection  
• Stop live and save final result  

---

📄 Smart Reporting  

• Automatic PDF report generation  
• Separate reports for upload & live detection  
• Includes detection count and alert status  

---

📊 Dashboard  

• Displays last detection result only  
• Shows alert status (Safe / Person detected)  
• Simple and clean UI  

---

📂 Project Structure  

• app.py → Main backend file  
• templates/ → HTML pages  
• static/ → CSS files  
• uploads/ → Input files  
• outputs/ → Detected images  
• reports/ → Generated PDFs  

---

⚠️ Current Limitations  

• Detects only persons (no object categories)  
• No cloud deployment  
• Works on local system  
• No face recognition
